# Changelog

Notable changes to `phone-rail`. The other plugins in this repository version separately.

The format follows [Keep a Changelog](https://keepachangelog.com/en/1.1.0/), and the version numbers
follow [Semantic Versioning](https://semver.org/spec/v2.0.0.html).

## 0.1.0

### Added

- **bb's icon rail, with a separate set of icons for phones.** Pick **Phone Rail** in Settings →
  Appearance → Navigation. On a desktop window it is bb's rail as you know it. On a phone-sized screen
  it shows the phone's own icons, in the phone's own order.
- **Customize navigation on a phone** opens a sheet with bb's own list: tick an icon to show it, drag to
  reorder it. **Hide from rail** on a phone hides the icon there only. **Same as wider windows** goes
  back to the shared set.
- **Customize phone navigation** in the desktop rail's More menu sets up the phone's icons from the
  desktop.
- The phone's set is saved on your bb server: it survives restarts, and every phone-sized screen
  shares it.
