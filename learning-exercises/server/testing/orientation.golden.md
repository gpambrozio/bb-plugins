A retrying HTTP client.

## Pipeline / workflow stages

1. Parse config
2. Send request
3. Retry on failure

## Key files

- `src/client.ts` — sends requests | every call goes through it
- `src/retry.ts` — decides retries | the policy lives here

## Core concepts

**Backoff**: Waiting longer after each failure. (src/retry.ts)

## Common gotchas

- Retries are off by default.
- Timeouts count per attempt.
